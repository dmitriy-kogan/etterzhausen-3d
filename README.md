# Etterzhausen 3D

Interaktive 3D-Konzeptstudie (Straße und drei Doppelhäuser) auf den Teilflächen B112 und L122, Flst. 198 / 198/21, Gemarkung Etterzhausen.

Keine Genehmigungsplanung und keine Vermessung. Gelände aus Schnitten interpoliert (±1 m), Bäume schematisch.

Aufruf: `index.html` über GitHub Pages. Three.js (MIT) liegt unter `lib/three`.
